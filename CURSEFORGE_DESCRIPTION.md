# CurseForge description (paste into project page)

**Default Quest Tracker Classic** is an unlimited quest tracker for WoW Classic Era that keeps the default Blizzard tracker look, with map/minimap markers and nameplate icons.

Questie is **not required**. This addon ships a slim quest/spawn database **derived from Questie Classic** community data.
